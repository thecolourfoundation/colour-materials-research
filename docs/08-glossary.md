# Glossary

> Part of [Colour Research](../README.md). Educational material. Numbers are approximate textbook or literature values unless sourced. See [research integrity](06-research-integrity.md).

| Term | Plain meaning |
|---|---|
| Matrix | The continuous material in a composite (copper) |
| Reinforcement or filler | The added particles (diamond) |
| Phonon | A packet of lattice vibration that carries heat |
| Thermal conductivity (k) | How well a material conducts heat |
| Thermal diffusivity (alpha) | How fast heat spreads through a material |
| Specific heat | Energy to warm a material by one degree |
| CTE | Coefficient of thermal expansion, growth per degree |
| Interface thermal resistance | Resistance to heat crossing a boundary |
| Wetting | A liquid or solid spreading on a surface |
| Contact angle | Shows wetting; above 90 degrees is non-wetting |
| Carbide former | An element that reacts with carbon to bond surfaces |
| Metallization | Coating diamond with a thin metal layer |
| Graphitization | Diamond turning to graphite |
| Green body | Pressed powder before sintering |
| Sintering | Fusing powder by heat, without melting everything |
| Relative density | Percent of the theoretical maximum density |
| Porosity | The fraction of empty space |
| SPS | Spark plasma sintering, fast pulsed-current sintering |
| HIP | Hot isostatic pressing, pressing with gas from all sides |
| HTHP | High-temperature high-pressure sintering |
| Infiltration | Pushing molten metal into a porous preform |
| Grain | A single crystal region in a metal |
| Microstructure | The internal pattern of grains, pores and phases |
| PSD | Particle size distribution, often quoted as D50 |
| Anisotropic | Properties differ by direction |
| Isotropic | Properties are the same in every direction |
| Heat spreader | A part that spreads heat sideways |
| TIM | Thermal interface material that fills gaps between surfaces |
| Junction temperature | The temperature of the chip itself |
| Heat flux | Heat per unit area, in W/cm2 |
| DoE | Design of experiments |
| SPC | Statistical process control |
| Gauge R&R | A test of measurement repeatability |
| FMEA | A structured study of failure modes |
| TRL and MRL | Technology and manufacturing readiness levels |
| Qualification | A customer's approval of your material |
| Yield | Percent of parts that pass |
| Traceability | A full record linking a sample to its inputs |
| OSAT | A company that assembles and tests chips for others |
| Near-net shape | A part made close to final size, to reduce cutting |
| EDM | Electrical discharge machining, cuts hard materials with sparks |
| Foundry | A company that makes products to customers' designs |
