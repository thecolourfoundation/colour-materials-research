# Security and safety policy

## What to report

- Anything in this repository or the Colour website that could cause **physical harm** if followed (for example, an unsafe powder, hydrogen or furnace instruction).
- Accidental exposure of **confidential or personal information**.
- Security problems with the website source.

## How to report

Email buildwithcolours@gmail.com with the subject "Security" or "Safety". Please do not open a public issue for sensitive reports. Include what you found, where, and how you would fix it.

We will acknowledge reports as soon as we can, fix confirmed issues promptly, and credit you if you wish.

## Scope note

This repository contains educational and research material, not operating procedures. Hazardous processes must only be performed by trained people in suitable facilities.
